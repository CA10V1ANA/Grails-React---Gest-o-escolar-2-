Projeto Grails - Gerenciamento de Alunos e Cursos

Aplicação desenvolvida em **Grails 5** para gerenciar **Alunos, Cursos e Matrículas**, com interface web básica (GSP) e API JSON para integração.

🚀 Tecnologias

- Grails 5.x  
- Java 11+  
- MySQL (ou outro banco compatível)  
- Gradle  
- Git  

📂 Estrutura do projeto

- `grails-app/` → controllers, domain, views (GSP)  
- `src/` → código adicional e utilitários  
- `build.gradle` → build e dependências  
- `.gitignore` → arquivos ignorados pelo Git  
- `gradlew` / `gradlew.bat` → scripts Gradle  

⚙️ Pré-requisitos

- Java JDK 11+  
- Grails 5.x  
- MySQL (ou outro banco compatível)  
- IDE (IntelliJ, VS Code, Eclipse)  
- Git
